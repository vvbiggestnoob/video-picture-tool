# 视频拼接工具 v4.4

本地 GUI 小工具：一次导入多段视频，每段可设多条「开始-结束」裁剪区间，按列表顺序拼接为一个 MP4。专为海康威视录像导出文件（IMKH 私有头 / MPEG-PS 流，扩展名常为 .mp4）做了兼容。

也支持**图片素材**（JPG/PNG/BMP/TIF/WebP，可多张、可与视频混排）：每张图片按「图片间隔」（默认 1 秒）连续显示后按顺序拼成视频。

全部处理在本地完成，不上传任何数据。

## 运行方式

- **直接双击 `视频拼接工具.exe`**（已内嵌 ffmpeg，可单独拷贝到任意位置使用）
- 或用 Python 运行：`python 视频拼接工具.py`（需同目录下有 `ffmpeg.exe`）

## 基本用法

1. 点 **📂 添加视频** 或 **🖼 添加图片**，均可多选；列表内可用 ↑↓ 调整顺序、删除单个、一键清空
2. 导入后每个素材卡片会**自动显示参数**（时长 / 分辨率 / 帧率 / 编码 / 音轨，图片显示分辨率），后台识别，不卡界面
3. 每段视频默认**整段参与拼接**；点 **＋ 添加裁剪区间** 可添加多条「开始 → 结束」
4. 图片**不支持裁剪**，每张的显示时长由顶部的 **图片间隔**（秒/张，默认 1，支持小数如 `2.5` 或 `0:30`）统一控制
5. 点 **▶ 开始拼接**，选择保存位置，等待完成

### 参数不一致时的对齐基准

- 所有素材参数一致：顶部显示绿色提示，不裁剪时将走无损直通
- 参数不一致：顶部显示**黄色警告横幅**，每段视频左侧的「基准」单选按钮变为可选——**输出将以基准视频的分辨率和帧率为准**，其余视频向其缩放对齐。默认选第一个视频，可改选任意一段
- 仅音轨不一致：画面无需对齐，只统一重编码音频（无音轨的片段补静音）

**时间格式**（三种等价写法，支持小数秒）：

| 写法 | 含义 |
|---|---|
| `90` 或 `90.5` | 90 秒 |
| `1:30` | 1 分 30 秒 |
| `1:02:03.5` | 1 小时 2 分 3.5 秒 |

- 开始留空 = 从 0 开始；结束留空 = 到该视频结尾
- 开始 ≥ 结束、或区间超出视频实际时长，会在开始前直接报错提示

## 支持的所有情况

### 一、素材类型

| 素材 | 支持情况 |
|---|---|
| 标准 MP4（H.264/H.265 等） | ✅ |
| 海康 PS 流（IMKH 私有头，扩展名常为 .mp4） | ✅ 自动识别，先剥头再无损转封装 |
| 海康 PS + 标准 MP4 混合 | ✅ |
| 静态图片（JPG/PNG/BMP/TIF/WebP，任意宽高比） | ✅ 每张图片显示「图片间隔」秒数，自动补静音轨 |
| 图片 + 视频混排 | ✅ 按列表顺序拼接 |
| 有音轨 / 无音轨混合 | ✅ 无音轨的片段自动补静音轨 |
| 音轨损坏（0 声道坏轨，海康 PS 常见） | ✅ 按无音轨处理 |
| 音轨解码失败 | ✅ 自动降级：全部改用静音轨重试一次 |
| 移动侦测录像（文件名时间跨度大于实际内容） | ✅ 显示和裁剪校验都以**实际内容时长**为准（如导出窗口 10 分钟、实际录像 6 分钟，显示 6 分钟） |

### 二、操作方式

| 操作 | 支持情况 |
|---|---|
| 多段整段拼接（不设任何区间） | ✅ |
| 单段视频裁 1 条区间 | ✅ |
| 单段视频裁多条区间（从一段录像提取多个片段拼一起） | ✅ |
| 多段视频各自裁多条区间后拼接 | ✅ |
| 结束时间留空裁到结尾 | ✅ |
| 多张图片按顺序转视频（每张固定时长） | ✅ 时长 = 「图片间隔」× 张数 |
| 图片插在视频中间混拼 | ✅ |
| 调整拼接顺序、删除、清空 | ✅ |

### 三、三条处理路径（速度差异的根源）

工具会根据素材自动选择最快的可行路径，日志中能看到走了哪条：

| 路径 | 触发条件 | 做法 | 速度 |
|---|---|---|---|
| **① 流复制直通** | 所有素材都是**原始 MP4**、编码参数完全一致（编码/分辨率/帧率/像素格式/音轨）、且**没有任何裁剪区间** | 不解码不重编码，直接拷贝压缩数据拼接 | 极快，取决于磁盘读写，几十分钟录像秒级完成 |
| **② 转封装 + 精确裁剪** | 含海康 PS，或参数不一致，或含图片素材，或设置了裁剪区间 | PS 先流复制转封装为 MP4（很快），之后 `-ss` 秒级定位到裁剪点，只解码选中片段再重编码 | 转封装快；重编码部分大约实时的 1~3 倍 |
| **③ 从头解码（回退）** | PS 转封装失败时的保底 | 从头解码并用滤镜重建时间轴 | 慢：取靠后的片段要先解码前面全部内容，仅作兜底 |

> **为什么海康 PS 不走直通**：海康 PS 流的码流带有私有填充包、DTS 时间戳重复等问题，转封装后直接拷贝拼接会产生部分播放器（如 Windows 自带播放器）无法播放的文件。因此 PS 素材即使整段拼接也一律重编码，保证输出一定能播。

**直通产物会校验总时长**，异常（或拼接失败）时自动回退到重编码路径，保证结果可靠。

### 四、参数不一致时的统一规则（走路径②重编码）

只要素材之间参数不一致，或设置了裁剪区间，就会重编码并统一为：

- 分辨率：**基准视频**的分辨率（宽高各取偶数），基准可在界面选择，默认第一个
- 帧率：**基准视频**的帧率（基准未知时回退 30fps）；像素格式：yuv420p
- 宽高比不同的素材：直接拉伸到目标分辨率（不会报错失败）
- 宽高比不同的**图片**：等比缩放 + 黑边居中补齐（letterbox/pillarbox），不拉伸变形
- 帧率：列表含图片且基准是图片时，默认 30fps
- 音频：AAC 44.1kHz 立体声 128k；无音轨片段补等长静音
- 时间戳：全部重建，拼接处连续无跳变
- 输出带 faststart（moov 前置，可边下边播）

### 五、日志关键词对照

| 日志出现 | 含义 |
|---|---|
| `流复制直通（不重新编码）` | 走了路径①，最快 |
| `无损转封装为 MP4（流复制）…` | 海康 PS 优化生效 |
| `转封装失败，回退为从头解码模式（较慢）` | 路径③兜底，属正常现象 |
| `开始处理：N 个片段` | 走重编码路径 |
| `保留音轨失败，全部改用静音轨重试…` | 音轨有问题，已自动降级（耗时会翻倍） |
| `直通产物时长异常…改用重新编码` | 直通校验未通过，已自动回退 |

## 限制说明

- **只要裁剪就必须重编码**：帧级精确的切点无法靠流复制实现（流复制只能切在关键帧上，误差可达数秒），这是所有同类软件的共同约束
- 直通要求**完全不裁剪且参数严格一致**；任何一个素材参数不同，整体走重编码
- 直通时保持素材原编码（例如全是 H.265 则输出 H.265）；重编码时统一输出 H.264 + AAC
- 重编码时输出帧率跟随基准视频：高帧率素材（如 60fps 基准选 25fps 视频）会降帧

## 命令行自检

验证程序是否正常（需要一个 95 秒以上的视频文件）：

```
视频拼接工具.exe --selftest 某个视频.mp4
```

输出 `SELFTEST PASS` 即正常（会裁 30-35s、60-65s、90-95s 三段拼成约 15 秒视频校验）。

图片转视频自检（传任意几张图片，`-t` 为每张显示秒数，默认 1）：

```
视频拼接工具.exe --selftest-images [-t 秒] 图片1 [图片2 ...]
```

输出 `SELFTEST-IMAGES PASS` 即正常（校验输出时长 ≈ 张数 × 间隔）。
